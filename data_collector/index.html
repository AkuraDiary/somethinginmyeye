Kinematic Handwriting Data Collector

Panduan Penggunaan Pengumpulan Data:

  1. Pilih Jenis Dataset (Train/Test) dan isikan Nama Anda di field Anotator.
  2. Pilih Mode (klasifikasi) (Normal/Dysgraphia) dan isikan Label sesuai dengan data yang akan dikumpulkan.
  3. Klik tombol Start Writing sebelum Anda mulai menulis untuk menghitung waktu jeda inisiasi (cognitive latency).
  4. Tuliskan huruf pada area kanvas di bawah (disarankan menggunakan stylus/pen tablet). Kanvas akan mengumpulkan data terkait arah coretan, kecepatan, tekanan, dan jeda antar coretan.
  5. Jika tulisan dirasa sudah selesai, klik Save Sample (In Server). Aplikasi akan secara otomatis menyimpan data tulisan dan data kinematic di server.
  6. Gunakan tombol Clear Canvas untuk membersihkan layar dan mengulang tulisan.

Prompt: Tulis huruf antara A - Z atau a - z (individual)
