Kinematic Handwriting Data Collector (And a part-timer Analyzer)

📖 Panduan Penggunaan Pengumpulan Data:

  1. Pilih Mode (klasifikasi) (Normal/Dyslexia) dan isikan Label sesuai dengan data yang akan dikumpulkan.
  2. Klik tombol Start Writing. sebelum anda mulai menulis untuk menghitung waktu jeda kognitif (cognitive latency) .
  3. Tuliskan huruf pada area kanvas di bawah (disarankan menggunakan stylus/pen tablet). Kanvas akan mengumpulkan data terkait dengan : arah coretan, kecepatan, tekanan, & jeda antara coretan
  4. Jika tulisan dirasa sudah selesai, klik Save Sample (In Server). Aplikasi akan secara otomatis menyimpan data tulisan dan data kinematic di server
  5. Gunakan tombol Clear Canvas untuk membersihkan layar dan mengulang tulisan.

Prompt: Tulis huruf antara A - Z atau a - z (individual)
